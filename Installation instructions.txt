Personal Asana Dashboard – Installation Instructions
=====================================================

PREREQUISITES
-------------
You need Node.js installed once on your PC. You don't need admin rights.

  1. Go to https://nodejs.org
  2. Download the big green "LTS" button
  3. Run the installer, click Next until it finishes

That's the only prerequisite. You won't need to touch Node.js again.


GETTING THE APP
---------------
  1. Open Command Prompt (press Win+R, type cmd, press Enter)
  2. Navigate to where you want the folder, e.g.:
       cd %USERPROFILE%\Desktop
  3. Run:
       git clone https://github.com/alonsabban/Asana-Personal-Dashboard.git
  4. This creates a folder called "personal-dashboard" — that's the app folder


RUNNING THE DASHBOARD
---------------------
Double-click START-DASHBOARD.bat. It will guide you from there.

The first time it runs, the dashboard will ask for your Asana token directly in the browser.
To make it easy to launch every day, right-click START-DASHBOARD.bat → "Send to" → "Desktop (create shortcut)"


NOTES
-----
- Your Asana token and settings are stored only on your own PC. Nothing is sent to any server
  other than Asana's own API.
- If something goes wrong, check dashboard-log.txt in the app folder and send it to
  Alon Sabban (asabban@paloaltonetworks.com).
