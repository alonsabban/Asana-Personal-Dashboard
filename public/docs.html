Local-only deployment

No cloud hosting. The app runs on localhost:3000. Colleagues clone the GitHub repo and double-click START-DASHBOARD.bat — it handles Node, npm install, git pull, and server start automatically.

Secrets never leave the server

The Asana PAT and AWS credentials live in ~/.dashboard_settings.json (mode 0600). The browser only ever receives boolean flags (hasPat, hasAI) — never the actual tokens.

All Asana calls are server-side

The browser never talks to Asana directly. All API calls go through Next.js route handlers, keeping the PAT server-side and allowing data normalization before the client sees it.

AI is optional and lazy

If no AWS credentials are configured, keyword + project-name matching handles classification. Bedrock is only called for tasks not already in the classification cache.

Voice broker is serverless

AWS Lambda + DynamoDB + CloudFront handle the mobile→dashboard bridge. No server port exposed. Tasks are consumed exactly once. TTL=7 days ensures DynamoDB self-cleans stale items.

Single paginated fetch

One API call fetches all incomplete tasks (up to 500) in pages of 100. Subtasks are included because they are also assigned to the user — they are identified by parent.gid and split before normalization.

Classification is a cache-first pipeline

Project-name matching runs first (zero latency). Only genuinely uncached tasks hit Bedrock. All tasks are batched into a single prompt to minimize API round-trips.

Auto-promote is one-time

The subtask In Progress scan fires at normalize time. Once a parent's status is written to Asana, the condition never triggers again — the status is now in the source of truth.

Concurrent write protection

The classification cache uses a module-level promise chain (cacheLock) so parallel refreshes cannot corrupt the JSON file with interleaved writes.

Flow 1 — First-run setup is blocking

SetupGate cannot be dismissed. The app is fully non-functional until a valid PAT is saved. Verification hits Asana live before storing anything, so invalid tokens are caught immediately.

Flow 2 — Edits are field-level, not form-level

Each cell saves independently on blur or Enter. There is no "save all" button. The PATCH endpoint accepts any subset of fields so each edit is a minimal API call.

Flow 3 — Classification degrades gracefully

If AWS credentials are absent, all tasks fall back to keyword + project-name matching. The subject is shown as "Other" when no match is found. No errors are surfaced to the user.

Flow 4 — Voice is async by design

The phone POSTs to the broker independently of the dashboard. Tasks accumulate in DynamoDB and are consumed in a single batch on the next dashboard refresh. No real-time connection needed.

v0.4 August 2026 Latest
🎤
Voice task creation from your phone
Tap the 🎤 Voice button in the top bar to get your personal mobile link. Open it on your phone, tap the mic, and speak your task — the app understands dates like "next Tuesday" automatically. Tasks land in your Asana the next time you refresh the dashboard. Works from anywhere, no VPN needed.
☑️
Select and act on multiple tasks at once
Check the boxes on the left of any tasks you want to act on, then choose Complete or Delete from the action bar that appears. Both actions sync to Asana immediately. Use the header checkbox to select everything visible at once.
📂
Assign a project to tasks that don't have one
Tasks with no project now show a + project button in the Project column. Click it, type to search, and pick — the task is moved into that project in Asana instantly. Useful for tasks created by voice or from the quick-add modal.
🔼
Subtask progress auto-updates parent status
When a subtask is marked In Progress, the parent task is automatically promoted to In Progress in Asana — no manual update needed. This happens silently in the background when you refresh, and only fires once.
✏️
Edit subtask status directly in the task panel
Expand any task to see its subtasks. Each subtask now shows its status pill — click it to change the status inline without leaving the dashboard. Same experience as editing the parent task's status.
v0.3 August 2026 Stable
🔽
Column filters
Each column header (Subject, Status, Project, Assignee) has a ▾ filter button. Click it to check or uncheck specific values — only matching tasks are shown. Active filters are saved across sessions, and a "Clear filters" button appears when any are active.
📌
Rename a task directly in the table
Single-click any task name to edit it inline — type and press Enter to save. Double-click still opens the full detail panel. The caret (▸) always expands/collapses independently.
📎
Description truncation with expand toggle
Long descriptions are trimmed to 20 words in the table view to keep rows compact. An "expand to show more" link reveals the full text without opening the detail panel. Click "show less" to collapse it again.
🔃
Sort and group preferences saved
The active sort column, sort direction, grouping mode (by Subject or Project), and all column filters are remembered between sessions. Re-open the dashboard and your view is exactly where you left it.
v0.2 July 2026 Stable
💬
Comments and subtasks side by side
Expand any task row to see a two-column panel: description + assignee on the left, comments and subtasks on the right. Add comments with @mentions and reply directly from the dashboard — no need to open Asana.
📊
Status field editing
Tasks with a custom Status field show a coloured pill in the table. Click the pill to change the status via a dropdown — options come live from your Asana project so they always match your workflow.
👤
Reassign tasks with typeahead search
Click the assignee field in the expanded task panel to search for a colleague by name. Results come from your Asana workspace. Select a name to reassign, or choose "Unassign" to clear it.
🏷
Move a task to a different project section
The Group column in the task table shows which section a task lives in. Click it to pick a different section from the same project — the task is moved in Asana immediately.
v0.1 June 2026 Stable
📋
All your Asana tasks in one place
The dashboard pulls every open task assigned to you across all workspaces and shows them in a single sortable, filterable table. No more switching between projects to see what's on your plate.
🎯
Today Focus panel
A summary card at the top shows overdue, due today, and due this week counts at a glance. Overdue tasks are highlighted in red throughout the dashboard so nothing slips through.
🤖
AI-powered subject classification
Tasks are automatically grouped into subjects (e.g. Customer, Strategy, Operations) using Claude AI. You can rename subjects, add classification hints, and manually override any task's subject with a single click.
⚡
Inline editing — due dates, descriptions, names
Click any due date, description, or task name in the table to edit it directly. Changes save to Asana on Enter or when you click away. No forms, no save buttons.
🚀
One-click setup
Clone the repo and double-click START-DASHBOARD.bat. The first time it opens, a setup screen asks for your Asana token — enter it once and you're done. Nothing is stored in the cloud.
